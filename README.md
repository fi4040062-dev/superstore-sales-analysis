# Superstore Sales Analysis

## Project Overview

This project analyzes the Sample Superstore dataset to understand sales, profit, customer behavior, and business performance.

The project focuses on data cleaning, exploratory data analysis (EDA), feature engineering, KPI calculation, and data visualization using Python.

## Dataset

* Dataset: Sample Superstore 2019
* Rows: 9,994
* Columns: 21

## Data Preparation

The data was prepared using Python through:

* Handling missing values
* Removing duplicate records
* Cleaning text columns
* Converting date columns
* Creating new analytical features
* Optimizing data types

## Analysis

The analysis includes:

* Sales by category and region
* Profit by category
* Sales and profit over time
* Sales by customer segment
* Discount vs. profit relationship
* Profit margin by category
* Top customers by sales
* KPI calculations

## Dashboards

Two dashboards were created to summarize the main findings:

* Sales Performance Dashboard
* Profit Performance Dashboard

The dashboards include KPI cards and multiple visualizations to provide a clear overview of business performance.

## Key Insights

* Technology generated the highest total sales and profit among the categories.
* Furniture generated relatively high sales but had the lowest profit margin.
* The West region recorded the highest total sales.
* Consumer was the largest customer segment by sales.
* Technology had the highest profit margin among the categories.
* Sales generally increased toward the end of the year, with November 2019 recording the highest monthly sales.
